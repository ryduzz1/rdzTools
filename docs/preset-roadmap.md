# Preset Roadmap

This scaffold is intentionally organized by outcome rather than implementation detail.

## Good next preset families

- word-by-word text reveals
- overshoot title builds
- cursor and typewriter systems
- chrome, glass, and frosted UI chips
- sticker, foam, and embossed looks
- glow + bloom signal treatments
- one-click rigging for null-based animation controls

## Product direction

To make this feel tactile instead of generic, the panel should eventually support:

- live preset intensity sliders
- mini preview thumbnails or motion gifs
- favorites and recent presets
- opinionated preset packs with a clear art direction
- parameter exposure after applying a preset
- stackable looks instead of single-pass effects

## Technical expansion

- split the host logic into separate JSX files by category
- add JSON-driven preset metadata for defaults and adjustable knobs
- build a packaging script for signed distribution
- add versioned migration for saved user presets
